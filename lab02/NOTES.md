Git — это программа (инструмент) для контроля версий, которая устанавливается на компьютер и локально отслеживает изменения в коде.
GitHub — это сайт (веб-платформа), облачный хостинг, куда разработчики выгружают свой код из Git, чтобы хранить его в сети и работать над проектом вместе с командой.
Использованные команды:
1. git status - показывает текущее состояние файлов в рабочем каталоге и индексе.
2. git diff — показывает конкретные изменения в коде, которые еще не добавлены в индекс
3. git diff --staged (или её синоним --cached) — показывает изменения, которые уже добавлены в индекс с помощью git add
