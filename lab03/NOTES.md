git log — это команда для просмотра истории коммитов в репозитории, которая отображает хронологический журнал изменений с указанием авторов, дат и комментариев к коммитам.
git show — это команда для просмотра детальной информации о конкретном объекте Git (обычно коммите), которая показывает его метаданные (автора, дату, сообщение) и весь список внесенных им изменений в коде.
git diff — это команда для сравнения различных состояний кода, которая выводит построчную разницу между рабочим каталогом, индексом (staged) или любыми двумя коммитами/ветками.
